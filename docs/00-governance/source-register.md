## Evidence rules

For every check, record: requirement/case ID, date, operator, source commit, environment, migration fingerprint, provider mode, action, expected result, actual result, redacted evidence location and outstanding limits. Documentation review, unit tests, signed database calls, authenticated browser behavior, live provider delivery and owner acceptance are separate evidence layers.

An absent prerequisite produces **Not executed / blocked by prerequisite**, not a pass. A test that reproduces a defect is evidence that the defect exists. It is not a product acceptance pass. A local result cannot certify production parity.
