# Visual reference and design status

The earlier interactive AcademyOS concept explores Workspace and Daily brief layouts, owner/trainer/guardian views, Arabic direction and light/dark themes. It uses synthetic data. The user's latest selected preferences were **Workspace, Light and 18 px card corners**.

The unchanged concept is archived at [AcademyOS design vision fragment](../assets/academyos-design-vision.fragment.html). It was created for the Codex visualization host and is retained as a reference fragment, not as a standalone production app or a complete portable website. The original file may initialize different controls; the selected preferences above and the [design system](ui-ux-design-system.md) govern the proposed implementation.

Original source: `/Users/moamenghareeb/.codex/visualizations/2026/10/20/01a15af0-ddbc-7d71-b8ff-a53b324189e8/academyos-design-vision.html`.

The concept demonstrates visual hierarchy and possible role experiences. It does not prove authentication, database integration, payments, permissions, accessibility compliance, durable offline behavior or production readiness. Its controls and numbers must not become an implementation specification by accident.

Next design deliverables during development: component states, phone attendance flow, complete guardian journey, financial review screens, real empty/error/conflict states, Arabic text expansion and accessible keyboard flows. Preserve the calm teal character while strengthening brand identity and the priority of actionable exceptions. Full screen coverage is tracked in the [screen catalog](screen-and-navigation-catalog.md).
