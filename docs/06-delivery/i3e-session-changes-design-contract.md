## Connected contract

Owner Training dated list → original occurrence → inspect effective date/time and publication/cancellation status → move or cancel → reason and exact before/after, retained Trainer/capacity/roster and visibility effect → explicit review acknowledgment → simulated atomic result → Back/reopen retained history. Week selection follows effective date; all program occurrences retains moved/canceled originals. Other occurrences and program recurrence stay unchanged. One-date edit is distinct from future recurrence edits and makeup.

A published occurrence exposes withdrawal first; existing I3d withdrawal is separately simulated and retains plan/history. Only the now-private date may move/cancel. The moved result stays private until a later separate publication review; the preview does not pretend to run the actual publication API. Canceled history remains inspectable without edit/publish/reinstate controls. No credits/fees/automatic makeup/family notice or attendance UI.
