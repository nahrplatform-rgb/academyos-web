## Scope, progress and recovery

A new scope loads the program definition on request. Returning focus checks current scope without resetting the dates and weekdays already entered. Leaving the scope prompts before discarding it. Ready still requires the exact audience and exception review before final confirmation. Preparing shows checked dates and its Resume action before the optional date list. The exact task uses localized counts. The existing preparation, pause, withdrawal, version, deadline and all-or-nothing rules remain canonical.

An existing operation reference takes precedence over a new job read. The tab verifies that it stored the original before sending a command. A failed storage write keeps the scope or job and withholds submission. A lost reply reopens the original in the same tab. Missing sign-in masks the preparation while keeping the reference. Reconciliation uses the existing operation endpoint. A known save with a failed result read shows that the save is confirmed and offers to load the result. Private authority is checked on every request.
