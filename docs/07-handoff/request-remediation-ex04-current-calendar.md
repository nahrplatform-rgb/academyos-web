## Changed behavior and ownership

Previously a Calendar without a safe stored/hinted period requested full Home, then requested Calendar. It now requests `owner_current_calendar` once. The API selector accepts only academy and `week|month`; the existing origin/body/session/no-store/fail-closed outer and signed-gateway read budgets remain. The new allowlisted RPC `x16_owner_current_calendar_v1` resolves current Owner/academy authority through `x15_context`, then delegates minimal records, authoritative total,50-row/26KB item bound and cursor generation to `x15_calendar`. It does not query Home task panels.

The database resolves branch-local today and returns a distinct `anchor`. Week remains today through today+6; month remains the Sunday-start42-day grid. The explicit anchor keeps the chosen window stable even if a second current-context check crosses midnight. Current context/setup/denial remain authoritative; no browser clock, cached role, client branch or general private cache is substituted. Current setup returns the existing resumable setup state without fake empty results. Trainer and Guardian contracts are unchanged.

`ExperienceJourney` keeps a resolved cold anchor separately from an explicit user/restored period. Installing the response updates display and safe navigation preferences, without adding another request-effect dependency or a one-time skip flag. The ref is read only by the request owner; the rendered date uses state. Real period/view/cursor/resume/reload changes still read current data. Explicit current-period recovery clears the resolved anchor before requesting it afresh. Existing dirty-input/write/unknown reconciliation paths are untouched; private results still disappear during current-authority checks and on denial. This is a scoped waterfall fix, not a new stale-display policy or a claim that every click is instant.

Changed boundaries: `apps/web/src/components/experience-workspace.tsx`, strict selectors/types in `apps/web/src/lib/experience-projections.ts`, signed read allowlist in `apps/web/src/lib/onboarding-gateway.ts`, and additive `supabase/migrations/20261102120000_owner_current_calendar.sql`.
