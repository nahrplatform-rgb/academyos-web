## Illustrative versus connected

Main-path data transitions and same-tab saved-step restoration are connected to a fictional local model. Delivery failure/unknown, wrong account, expired/revoked, loading/saving, no membership, restricted and stale examples can be selected deterministically in Design review controls. They illustrate copy and recovery routes. They are not real authentication, async worker, server-save, operation-idempotency, concurrency or offline simulations. Unknown check reads existing fictional state and issues no replacement. The simplified stale illustration keeps the draft but lacks a complete before/after version comparison.

No sign-in/recovery provider screens or actual email-verification loop are connected; the recipient button explicitly changes a fictional review persona. Phone setup is present in source; dedicated trainer/guardian/player phone journeys remain future batches. The timezone selector is an explicit illustrative subset, not the complete production IANA picker. List data is small; production bounded paging, complete scope, safe cursor and bulk authority remain implementation contracts.
