Open [the prototype](prototype/index.html) or [the local preview](http://127.0.0.1:8765/prototype/index.html) while the server is running. Use the sidebar/review controls:

- **All design journeys:** evaluations/publication; family finance/receipt/unknown result; compensation exceptions/statement; platform plan/proof/recovery; communications; private media; support; stock movements; exports/privacy; full Services & Operations/incident; identity/authority/preferences; import/archive; later offline/native concepts.

English/Arabic, light/dark and Phone layout are available. Domain review controls reproduce loading/empty/failed/restricted states. Domain actions advance deterministic simulated outcomes; no actual sign-in, API, payment, invitation, message, upload, provider change or deletion. Financial amounts are reviewer-entered fictional units or unavailable pending policy, never approved fees/rates/prices. A local complete-scope CSV download contains only60 generated fictional rows.

Saved fictional records persist in the current tab. Unsaved forms/attendance reset on refresh; studio field drafts may survive locale/theme changes in memory. Reset clears this demonstration only. Persona controls are review tools, not authorization. macOS frame is retained as presentation.
